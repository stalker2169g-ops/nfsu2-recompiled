# Русские шрифты v2: отдельные текстуры

Сборка исправляет конфликт имён при выборе текстур шрифта. Проверка на телефоне ещё требуется.

## Основание для правки

В присланном отчёте NFSU2-diagnostico-20261025-144800.zip контрольные суммы подтверждают установку предыдущей пары ресурсов. Движок использует новые координаты кириллических символов, но для CONDUITMDITC_TT21I (хеш 5b9d88b9) журнал FONT_TRACE показывает размер 1024×1024 вместо 512×256 в изменённом LanguageTextures.bin. На экране остаются фрагменты букв. Переключение декодирования текстур на CPU не помогло.

## Что изменено

Каждый восстановленный атлас получает отдельное имя NFSRU2_V2_0…NFSRU2_V2_6 и соответствующий хеш. Ссылки на текстуры в English.bin обновляются одновременно с координатами. Имена самих шрифтов, строки, игровая таблица преобразования, размеры символов и кернинг сохраняются. Исходные общие текстуры остаются в архиве, чтобы другие языковые таблицы продолжали ссылаться на свои ресурсы.

При Play версия v2 распознаёт установленное предыдущее исправление по маркеру и фактическим SHA256, проверяет оригинальные резервные копии и автоматически пересобирает пару из оригиналов. Маркер переводится в восстанавливаемую фазу до миграции; повторный запуск завершает прерванную операцию. Резервные копии не перезаписываются. Неизвестные файлы не изменяются.

Загружать игровой архив заново и вручную заменять файлы не требуется. Начертание по-прежнему системное, а не оригинальное игровое. Выбирается «Русский (English.bin)». Точечный FONT_TRACE и список ресурсов в диагностическом ZIP сохранены.

## Проверки

Код APK: 0ba7d752f2fdfd3a02e867a1e096e109a6b83a0d.
Сборка: https://github.com/stalker2169g-ops/nfsu2-recompiled/actions/runs/40283339852
Android-тесты: https://github.com/stalker2169g-ops/nfsu2-recompiled/actions/runs/40283339932

Публикация workflow требует прохождения восьми Android instrumentation-тестов, проверки совпадения SHA256 APK и ARM64-библиотеки, выполнения CP1251-кода и штатного распаковщика/расчёта координат букв под Unicorn. Android-тесты включают уникальные ссылки на атласы, сохранение общей текстуры, миграцию старого маркера, резервные копии, повторный запуск и восстановление после прерывания.

Это не проверка всей игры на устройстве. Читаемая кириллица в игровом меню пока НЕ подтверждена. После установки нужен скриншот того же меню; при сохранении проблемы диагностический ZIP должен показать NFSRU2_V2_* и фактические размеры выбранных текстур.
