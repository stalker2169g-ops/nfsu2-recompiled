# Исправление кириллицы в ARM64 runtime — 25 октября 2026

Эта версия включает скомпилированное исправление в нативной библиотеке. Предыдущий релиз `arm64-launcher-test-40142832311` был только тестом упаковки и не включал исправление кодировки.

## Что изменено

- В SHA-проверенную ARM64-библиотеку официального v0.14.10 добавлены обработчики CP1251, скомпилированные Android NDK 28.2.13676358.
- Заменены нативные точки входа `MultiByteToWideChar`, `WideCharToMultiByte`, `GetACP`, `GetCPInfo`, `GetThreadLocale`; добавлена поддержка русской локали в `LCMapStringW`.
- Нативный выбор языка принимает Russian. Для него ANSI codepage становится 1251, а LCID — 0x419. Для остальных поддерживаемых языков сохраняется CP1252.
- Поиск языковых файлов в лаунчере учитывает варианты регистра, например `Russian.bin` и `RUSSIAN.BIN`.
- Сохранены CP1252, CP437 и UTF-8; переходы внутри исправления учитывают ASLR.
- Исходные адреса существующего кода и данных ELF не перемещаются. Добавлен явно отображаемый заголовок PT_PHDR для загрузчика Android.
- Повторное удаление символов из готовых библиотек при упаковке отключено, чтобы APK содержал ровно проверенные байты.

Это не полная пересборка кода игры. Неизменённые части runtime и код игры берутся из официального ARM64 APK v0.14.10; исправленные HLE-функции компилируются отдельно и подключаются к его нативным точкам входа. Скрипт отказывается применять замену к библиотеке с другой SHA-256.

## Что проверено

[Сборка и проверки Actions 40181999283](https://github.com/stalker2169g-ops/nfsu2-recompiled/actions/runs/40181999283), исходный коммит `d7932ec2b581fb126224d8e9fb04f65e54a12a65`.

Проверки исполняют настоящий ARM64-код оригинальной и изменённой библиотек в Unicorn. Для окружения моделируются выделение памяти, журналирование, математика и гостевая память; Android, Vulkan и сама игра не запускаются.

- В оригинальной библиотеке воспроизведён отказ CP1251 с Win32-ошибкой 87.
- В изменённой библиотеке проверены CP1251 ↔ UTF-16, русский алфавит, Ё/ё, №, строки с завершающим нулём и все байты CP1251.
- Проверены UTF-8 с дополнительными Unicode-символами, CP1252 и CP437.
- Проверены выбор русского/испанского языка, ACP, LCID и русское преобразование регистра.
- Проверены недостаточный буфер, неверный UTF-8, неверный UTF-16, символ замены, GetLastError и очистка гостевого stdcall-стека.
- Те же проверки проходят при нулевой базе и при смещении библиотеки `0x1000000000`.
- Сборка APK проверяет побайтовое совпадение упакованных библиотек с проверенными файлами и подпись APK.

## Что ещё не подтверждено

**Отображение кириллицы в меню и игровых шрифтах на Android не проверено.** Тесты подтверждают преобразование кодировки и работу нативных обработчиков, но не покрывают Android-загрузчик на устройстве, чтение конкретного набора игровых ресурсов, запуск игры или отрисовку текста.

Шрифтовые текстуры не заменялись: без проверки ресурсов игры нельзя установить, нужна ли их замена. Для русских ресурсов `LANGUAGES/Russian.bin` выберите «Русский» в настройке языка лаунчера. Игровые данные остаются на устройстве в `/sdcard/nfsu2`; APK их не содержит.
