# Russian fonts v3 — проверяет владелец на устройстве

После v2 пользователь сообщил о полном исчезновении текста. Эта сборка меняет способ загрузки уникальных атласов: вместо сжатых записей с загрузкой по запросу используется несжатый TPK с таблицами TextureInfo/GamePixelFormat. Имена NFSRU2_V3_* и ссылки на них в English.bin обновляются одновременно.

При Play установленная пара предыдущей версии распознаётся по маркеру и контрольным суммам, оригинальные резервные копии проверяются и используются для пересборки. Копии не перезаписываются.

По прямому указанию владельца автоматические Android/Unicorn-тесты отключены. Выполняется сборка APK; игровое отображение проверяет владелец. Работоспособность кириллицы не подтверждена.

Код APK: 7513abb139e73ac67db9dd82de32e2619d8c5a63
Сборка: https://github.com/stalker2169g-ops/nfsu2-recompiled/actions/runs/40284060190

Установить APK, нажать Play, проверить прежнее меню. Вручную менять игровые файлы не нужно. FONT_TRACE и отчёт ресурсов сохранены, если потребуется отчёт с телефона.
