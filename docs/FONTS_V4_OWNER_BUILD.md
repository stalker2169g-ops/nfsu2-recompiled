# Русские шрифты v4

Предыдущие версии не исправили меню: v2 убрала надписи, v3 вернула фрагменты букв. Работоспособность v4 на телефоне пока не подтверждена.

Новые атласы переведены из DXT3 в обычные 32-битные A8R8G8B8 (BGRA в файле), с соответствующими размером изображения, типом пикселей и форматом в метаданных TPK. Это исключает декодирование блоков DXT для восстановленных шрифтов. Уникальные имена NFSRU2_V4_* и несжатые таблицы TPK сохранены. Старые общие текстуры остаются в исходном формате.

При Play выполняется автоматический переход с предыдущей версии по маркеру и контрольным суммам. Используются уже имеющиеся оригинальные резервные копии; перезаписывать их и вручную заменять ресурсы не требуется.

По указанию владельца автотесты Android/Unicorn отключены. Выполнена сборка APK, игровую проверку выполняет владелец. Дополнительные файлы и журналы у пользователя не запрашиваются.
